# ESP32-S3-Mini-Portable-MP3-Player
THE OSY-1 is an open-source ESP32-S3 portable MP3 player featuring a 240x240 ST7789 display, PCM5100A I2S stereo audio, MicroSD playback, physical controls, and deep sleep support. Built with Arduino for compact retro-style handheld music devices and future expandable audio features.
